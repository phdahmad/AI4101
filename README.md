## الملفات

| الملف | الدور |
|---|---|
| `index.html` | الهيكل: الشريط العلوي، شريط الإحصاءات، القائمة الجانبية، واستدعاء الملفات بالترتيب |
| `landing.js` | **صفحة الهبوط وحدها** — كتلة `LANDING` في أعلاه تتحكم بالصور والعناوين والبطاقات. بدّلها للمناسبات دون لمس أي ملف آخر |
| `styles.css` | التنسيق + الوضعان الفاتح (افتراضي) والداكن + تنسيق الطباعة |
| `content.js` | **محتوى المقرر** — مصفوفة `COURSE_CONTENT` بسبع وحدات |
| `quizzes.js` | **بنك الأسئلة** — كائن `QUIZ_BANK` مفتاحه رقم الوحدة |
| `app.js` | المحرّك: المسيِّر، قائمة المحتويات، تتبّع موضع القراءة، Mark as read، تصحيح الاختبار، منطق "أكمل من حيث توقّفت" |
| `assets/` | صور صفحة الهبوط بصيغة WebP: نسخة عريضة ونسخة عمودية للجوال، ولكلٍّ مقاسان |

**ترتيب الاستدعاء في `index.html` مهم:** `landing.js` ثم `content.js` ثم `quizzes.js` ثم `app.js`. وإن سقط أحد ملفات البيانات ظهرت رسالة صريحة تسمّيه بدل صفحة بيضاء.

**تغيير صفحة الهبوط لمناسبة (اليوم الوطني مثلاً):** ضع الصورتين الجديدتين في `assets/`، وعدّل في `landing.js` قيم `images` و`tagline` و`quote`. أو احتفظ بنسخة `landing-national-day.js` وبدّل اسم الملف في سطر الاستدعاء. بقية الموقع لا يتأثر.

لا توجد إطارات عمل (no frameworks). المكتبات الخارجية من CDN: KaTeX للرياضيات، highlight.js للكود، Google Fonts (Crimson Pro / Inter / JetBrains Mono).

## إمكانية الوصول والاستجابة

- **الوضع الفاتح والداكن**: كلاهما يحقق WCAG AA — أدنى تباين نص 4.67:1 في الفاتح و4.58:1 في الداكن. عُدّلت ثلاثة ألوان في اللوحة الفاتحة لتحقيق ذلك: `--ink-mute` و`--gold` و`--teal`. أُضيف `--gold-soft` للاستخدام الزخرفي فقط (حدود وتعبئة) ولا يُستخدم للنصوص أبداً.
- **النص فوق الأشكال الملوّنة** يستخدم `var(--bg)` لا `#fff`، فينقلب مع الثيم تلقائياً.
- **الجوال أولاً**: لا تمرير أفقي عند 360 بكسل في أي صفحة، وأحجام الخطوط تتدرّج بـ`clamp()`، ومناطق اللمس ≥44 بكسل عبر `@media (pointer: coarse)`.
- **`prefers-reduced-motion`** مدعوم، وتظهر حلقة تركيز واضحة للوحة المفاتيح في الوضعين.

## كيف تُضاف وحدة جديدة

في `content.js`، كل وحدة كائن بهذا الشكل:

```js
{
  id: 4,
  title: "...",
  subtitle: "العنوان الفرعي المائل تحت الاسم",
  shortDesc: "سطر واحد يظهر في البطاقة",
  hours: 8,
  story: "فقرة تمهيدية تظهر أعلى صفحة الوحدة",
  objectives: ["...", "..."],
  sections: [ { title: "...", body: `HTML` } ],
  resources: [ { type: "video|blog|paper|docs", title, author, url } ]
}
```

وفي `quizzes.js`:

```js
4: [ { q: "...", choices: ["أ","ب","ج","د"], correct: 1, explanation: "..." } ]
```

`correct` فهرس يبدأ من صفر.

## مكوّنات المحتوى المتاحة (أسلوب التبسيط)

استخدمها داخل `body` لأي قسم — كلها منسّقة مسبقاً في `styles.css`:

| الصنف | الاستخدام |
|---|---|
| `.analogy` + `.analogy-label` | تشبيه من الحياة اليومية قبل التعريف التقني |
| `.definition` | التعريف الرسمي المختصر |
| `.aha` + `.aha-label` | "لحظة الفهم" — الفكرة التي تغيّر نظرة الطالب |
| `.callout intuition` / `.callout note` / `.callout warning` | ملاحظة جانبية بأيقونة |
| `ol.steps` | خطوات مرقّمة مع شرح لكل خطوة |
| `.diagram` + `.diagram-caption` | رسم SVG مع تعليق |
| `.applications` > `.app-grid` > `.app-card` | شبكة تطبيقات واقعية |
| `.before-after` > `.ba-col before` / `.ba-col after` | مقارنة قبل/بعد |
| `.checkpoint` + `<details>` | سؤال تحقّق بإجابة مطويّة |
| `p.reading-time` | "6 min read" في نهاية القسم |

زر **Mark as read** وتسمية **Section 3.4** يضيفهما `app.js` تلقائياً لكل قسم — لا تكتبهما داخل `body`.
| `<pre><code class="language-python">` | كود بايثون مع تلوين |

**مهم في رسوم SVG:** استخدم متغيّرات CSS للألوان (`fill="var(--accent)"`) لا قيَماً ثابتة، وإلا لن تعمل مع الثيم الداكن. وداخل نص JS استخدم `&lt;` بدل `<` في الكود البرمجي.

## ملاحظات فنية

- تتبّع التقدّم في `localStorage` تحت المفتاح `ai4101_progress_v2`، والثيم تحت `ai4101_theme`. صيغة التقدّم: `{ "3": { read: [0,1,2], score: 9, total: 12 } }` — نسبة الوحدة = الأقسام المقروءة ÷ عدد أقسامها، والنسبة العامة = متوسط نسب الوحدات السبع.
- أسماء أصناف CSS تستخدم `module-` لا `unit-`؛ إن نسخت قوالب من موقع ADL فأعد التسمية.
- الرياضيات تُكتب بين `$...$` أو `$$...$$` ويصيّرها KaTeX.
- جميع روابط الفيديو والمصادر في الوحدة 3 تم التحقّق منها فعلياً.
