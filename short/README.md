# AI4101 — Artificial Intelligence Principles

موقع تفاعلي لمحتوى مقرر **AI4101 — مبادئ الذكاء الاصطناعي** (جامعة أم القرى).
صفحة HTML واحدة مكتفية بذاتها، تحتوي على:

- 7 وحدات (60 ساعة تدريسية) مع شرح كامل، أمثلة، ومخططات
- ~48 سؤال تقييم ذاتي موزعة على نهاية كل وحدة
- تتبع تقدم الطالب تلقائياً عبر `localStorage` في المتصفح
- شريط تقدم عام، ونسبة إنجاز لكل وحدة، ومخزن الإجابات الصحيحة
- زر إعادة تعيين، وزر طباعة، ووضع طباعة منظّم

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً: `ai4101-course`).
2. ارفع ملف **`index.html`** إلى جذر المستودع.
3. اذهب إلى `Settings → Pages`.
4. في `Source`، اختر فرع `main` ومجلد `/ (root)`.
5. احفظ. خلال دقيقة، سيكون الموقع متاحاً على:
   `https://<username>.github.io/ai4101-course/`

> الملف الذي ينشر في GitHub Pages يجب أن يكون اسمه `index.html` ليُفتح تلقائياً.

## ملاحظات

- بيانات التقدم تُخزَّن محلياً في متصفح الطالب فقط (لا يوجد خادم).
- الملف يعمل أيضاً بدون اتصال بالإنترنت بعد التحميل الأول للخطوط من Google Fonts.
- لو أراد الطالب البدء من جديد، يضغط على زر "Reset Progress" في الأعلى.

## المرجع الأساسي

Russell, S., & Norvig, P. (2020). *Artificial Intelligence: A Modern Approach* (4th ed.). Prentice Hall.
